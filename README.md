# Описание функциональности и интерфейса (Лабораторная работа 1)

Приложение предназначено для проведения экспериментов, исследования временной сложности и анализа эффективности алгоритмов. Графический интерфейс предоставляет инструменты для настройки параметров тестирования, запуска замеров, анализа результатов и навигации по истории тестов.

## Доступные алгоритмы и операции

В интерфейсе приложения доступен выбор нескольких категорий алгоритмов для замера производительности:

1. **Векторные операции и базовые алгоритмы:**
* Вычисление постоянной функции, суммы и произведения элементов массива.
* Вычисление значений полинома (сравнение наивного метода и схемы Горнера).
* Алгоритмы сортировки массивов: сортировка пузырьком, быстрая сортировка (QuickSort) и Timsort.


2. **Матричные операции:**
* Перемножение прямоугольных матриц с фиксацией времени выполнения.


3. **Алгоритмы обработки массивов:**
* Проверка наличия повторяющихся элементов.
* Разворот (инвертирование) массива на месте.
* Сортировка Шелла (Shell Sort).


4. **Алгоритмы возведения в степень (с точным подсчетом итераций):**
* Итеративный метод $O(n)$.
* Рекурсивный метод $O(n)$ (с защитой от переполнения стека при больших значениях $n$).
* Бинарное (быстрое) возведение в степень $O(\log n)$.

## Элементы управления и структура UI

**1. Панель настройки эксперимента**

* **Выбор алгоритма:** выпадающий список для выбора нужной операции или метода сортировки.
* **Параметры диапазона:** поля ввода для задания начального размера данных (`StartN`), конечного размера (`EndN`) и шага изменения (`Step`).



**2. Навигация по истории (Сессии замеров)**

* Все проведенные эксперименты автоматически сохраняются и группируются в сессии.


* Выбор нужного теста осуществляется через выпадающий список с форматом записи:
`ДД.ММ.ГГГГ ЧЧ:ММ:СС | Название алгоритма (N=Минимальное..Максимальное)`.



**3. Таблица результатов**
Итоговые данные выводятся в виде детализированной таблицы со следующими столбцами:

* **Название алгоритма**.


* **Размер входных данных (N)**.


* **Номер запуска:** порядковый номер прогона для оценки стабильности результатов.


* **Время выполнения:** затраченное время в миллисекундах.


* **Количество шагов:** число базовых операций (выводится для алгоритмов с подсчетом итераций).


* **Дата и время проведения теста**.



**4. Системные функции и оптимизация**

* **Автоматическое кэширование:** при повторном запросе вычислений для ранее рассчитанных комбинаций алгоритма и $N$ результаты мгновенно загружаются из базы данных без повторного запуска тестов.
